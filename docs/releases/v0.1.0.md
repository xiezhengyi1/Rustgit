## 中文

RustGit 首个源码与桌面安装包发布：在自己的电脑上保存项目版本，并在 macOS 和 Windows 之间共享。

### 下载

- **macOS Apple Silicon：** `RustGit-0.1.0-macos-arm64.dmg`，也提供 ZIP；要求 macOS 14+。
- **Windows x64：** `RustGit-0.1.0-windows-x64-setup.exe`；要求 Windows 10 1809+ 或 Windows 11。
- **校验：** 下载 `SHA256SUMS`，核对安装包 SHA256。

### 本版内容

- 「提交并共享」一次完成本地提交和发送；发送失败保留提交，可单独重试共享。
- 自动读取项目内 `.gitignore` 和嵌套规则，支持 `.rgitignore`。
- 保存版本、文件差异、分支、合并、文件恢复和撤销。
- 自托管共享、加密连接、设备身份验证、邀请和权限管理。
- 中英文桌面界面，以及最近项目切换。

### 验证与限制

macOS 桌面包已构建并运行。Windows 新版已在真实电脑上替换安装，实际点击「提交并共享」后，托管端收到提交；第二副本通过 CLI 拉取文件并核对 SHA256 一致。另一个 3,425 文件、约 63 MB 的项目已在 Windows 核实完整落盘。

这是早期版本。macOS 包为临时签名且未经 Apple 公证；Windows 安装包未签名。macOS 未提供 Intel 桌面包。Windows 缺少 WebView2 时安装器需联网下载。Windows 符号链接恢复不受支持，跨平台项目应忽略依赖缓存、构建目录和 macOS 应用包。Windows 失败、取消和重试路径有自动化覆盖，尚未做对应的原生手动测试。

RustGit 使用独立 `.rgit` 格式，当前不兼容 Git 仓库协议。

使用说明：[中文 README](https://github.com/xiezhengyi1/Rustgit/blob/v0.1.0/README.md)。

## English

The first RustGit source and desktop release: save project versions on your own computer and share them between macOS and Windows.

### Downloads

- **macOS Apple Silicon:** `RustGit-0.1.0-macos-arm64.dmg`, with a ZIP alternative; requires macOS 14+.
- **Windows x64:** `RustGit-0.1.0-windows-x64-setup.exe`; requires Windows 10 1809+ or Windows 11.
- **Integrity:** Download `SHA256SUMS` and verify the installer SHA256.

### Included

- **Commit and share** saves a local commit and sends it in one action. Failed sends retain the commit and offer a send-only retry.
- Project `.gitignore` files and nested rules, plus `.rgitignore`.
- Version history, diffs, branches, merges, file restoration, and revert.
- Self-hosted sharing, encrypted connections, device authentication, invitations, and access roles.
- English/Chinese desktop interfaces and recent-project switching.

### Verification and limitations

The macOS desktop package has been built and run. The new Windows installer was installed over the previous version on a real computer. Clicking **Commit and share** published a commit; a second working copy pulled the file through the CLI with a matching SHA256 hash. A separate project with 3,425 files, about 63 MB, was also verified on disk on Windows.

This is an early release. The macOS package is ad-hoc signed and not notarized; the Windows installer is unsigned. No Intel Mac desktop package is included. Windows installation needs internet if WebView2 is missing. Windows cannot restore symbolic links; exclude dependency caches, build outputs, and macOS app bundles from cross-platform projects. Windows failure, cancellation, and retry paths have automated coverage but have not received equivalent native manual testing.

RustGit uses its own `.rgit` format and does not currently support Git repository protocols.
